# Support

Use a GitHub issue for reproducible bugs, adapter requests, and documentation
problems. Include the Spatial Presence version, Home Assistant version, radar
model, relevant entity IDs, and a minimized map with private geometry removed.

Use GitHub private vulnerability reporting for security or privacy issues.
Do not post tokens, private Home Assistant URLs, precise home layouts, or
recorded target histories in an issue.

This is a community project, so response times are not guaranteed. Donations
are appreciated but do not purchase feature priority, private troubleshooting,
or early access to security fixes.
