# Contributing

Thank you for improving Spatial Presence.

1. Discuss changes to the map schema, adapter contract or persistence model in
   an issue before implementation.
2. Keep hardware-specific entity naming inside an adapter.
3. Add geometry golden tests for any transform or unit conversion change.
4. Run `npm test`, `npm run typecheck`, `npm run build`, and Python compile
   checks before opening a pull request.
5. Never include Home Assistant tokens, private URLs, precise real-home maps or
   recorded target data in fixtures.

By participating, you agree to follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
